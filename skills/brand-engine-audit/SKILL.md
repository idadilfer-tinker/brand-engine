# Standing tool -- Engine Audit

Read `../_shared/protocol.md` first.

## What this is for

Someone can want to know "is this worth doing" before they've committed to
an engagement at all. This tool answers that without assuming Discovery has
started -- it's a lighter-weight, faster diagnostic, meant to end in a
recommendation, not a full Discovery Brief.

## Triage

Confirm first: is there an existing brand to evaluate, or is the question
really "should we build from zero" (which is closer to a Discovery
conversation than an audit -- still fine to run here, but say so explicitly
in the output rather than pretending this is a from-zero audit).

## Diagnosis

- What does the current brand kit actually consist of -- a static PDF, a
  Figma file nobody outside design opens, or something more alive already?
- Is there any element (shape, color, gesture) with real recognition
  equity, or is everything replaceable without real loss?
- Is production velocity outpacing design headcount right now, or is this
  a preventive question ahead of that happening?
- Roughly how many distinct formats does the brand already need to work
  across?

This is meant to move fast -- one or two rounds of questions, not a full
Discovery-style interview.

## Closure conditions

Only produce the Audit Brief once:

- The state of the existing kit is known (or "none" is confirmed).
- Any real equity has been identified, or its absence confirmed.
- A tier recommendation can be made with actual reasoning behind it, not a
  default.

## Formal artifact: Audit Brief

Use the shared output shell. Stage-specific content:

- **Current judgment**: recommended tier -- Audit was just this
  conversation; the recommendation is Refresh, Build, or "not ready yet."
- **Key evidence**: what in the current kit supports that recommendation.
- **Primary thread**: the single biggest risk if this prospect moves
  forward on the wrong tier (e.g., proposing a Build when there's real
  unclaimed equity, or a Refresh when there's nothing worth keeping).
- **What not to do yet**: don't propose a full engagement scope from this
  Brief alone -- that's what Discovery is for, even on a fast-tracked
  engagement.
- **Recommended next step**: `brand-engine-01-discovery` if moving forward.
- **Key conclusions for next skill**: whatever equity or format information
  came up here so Discovery doesn't re-ask it from zero.
